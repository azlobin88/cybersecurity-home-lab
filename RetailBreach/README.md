# Лаборатория RetailBreach сайт cyberdefenders.org

Исследуйте сетевой трафик с помощью Wireshark, чтобы идентифицировать TTP злоумышленников, извлечь полезные нагрузки XSS и токены сеанса и определить используемые уязвимости веб-приложений.

## Сценарий
В последние дни ShopSphere, известная онлайн-платформа розничной торговли, испытала необычную административную активность в ночные часы. Эти логины совпадают с притоком жалоб клиентов на необъяснимые аномалии учетной записи, что вызывает опасения по поводу потенциального нарушения безопасности. Первоначальные наблюдения предполагают несанкционированный доступ к административным счетам, что потенциально указывает на более глубокий системный компромисс.

Ваша миссия состоит в том, чтобы исследовать захваченный сетевой трафик, чтобы определить характер и источник нарушения. Определение того, как злоумышленники проникли в систему, и определение их методов будет иметь решающее значение для понимания масштабов атаки и смягчения ее воздействия.
